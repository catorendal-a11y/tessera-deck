    INTEGRATIONS
    Plugins
    Plugins are small programs in the plugins folder that add keys, values and actions. A plugin runs with your own Windows rights, so only turn on plugins you trust. Each one gets its own limited access to Tessera.
    

    TEMPLATES
    Page from a template
    Pick a template to see the page, then add it. You can change every key afterwards.
    

    PANEL
    Rail
    The buttons down the left side of the panel: the screens, then up to three shortcuts to a page. The panel has room for seven.
    

    On the panel
    Screens Turn a screen on or off, and move it up or down. Keys is always there.
    Shortcuts A shortcut opens a page, or runs steps like a key without leaving the screen you are on. After a page, Keys takes you back.
    

    

    AUTOMATIC BACKUPS
    Restore a backup
    Tessera keeps a copy of your configuration while you edit (the latest 30). Restoring keeps the current configuration as a backup too.
